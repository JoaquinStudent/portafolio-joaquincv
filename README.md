# Portafolio — Ingeniería de Software

Sitio personal de portafolio hecho con HTML, CSS y JavaScript puro.

## Uso rápido

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repo.git
   cd tu-repo
   ```
2. Abre `index.html` en tu navegador (no necesita servidor ni build).

## Personalización

Edita **`js/data.js`** para cambiar toda la información del sitio: nombre, descripción, proyectos, habilidades, links y más. No necesitas tocar HTML ni CSS.

## Estructura

```
├── index.html          ← página principal
├── css/style.css       ← estilos
├── js/
│   ├── data.js         ← TUS DATOS (edita solo este archivo)
│   └── main.js         ← lógica de renderizado
└── assets/             ← imágenes, CV, etc.
```

## Deploy

Activa GitHub Pages en **Settings → Pages → Source: main / root** y tu sitio estará en `https://tu-usuario.github.io/tu-repo/`.
